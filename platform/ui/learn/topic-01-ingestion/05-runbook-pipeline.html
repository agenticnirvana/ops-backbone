Mechanics

What / why / how

What

Parse labels from the file. Window the text. Embed each window. Write (id, text, meta, vector).

Why

Questions hit a paragraph, not a wiki. Labels let you constrain “checkout only” after similarity.

How

Hash files; re-embed what changed. Full rebuild writes a new collection and swaps an alias so readers never see a torn index.

In production

The “chat with this PDF” factory

Drop-zone sync

Nightly pull from Drive / SharePoint, chunk, embed, store. Morning queries hit last night’s index.

Changing SOPs

Re-run only deltas or you cite last year’s refund policy.

Failure mode

Most “RAG is dumb” tickets are bad windows or missing metadata — not a weak generator.

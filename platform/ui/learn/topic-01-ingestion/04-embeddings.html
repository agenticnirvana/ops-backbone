The model that writes the map

An embedding model is a neural network that turns unstructured input — a sentence, an image, a clip — into a vector of features. Similar items land in the same region of that space. The vector database does not “understand” language; it only stores and compares the numbers this model emits.

same checkpoint on ingest and on query

Mechanics

What / why / how

What

A neural encoder: raw item in, fixed-length floats out. Ours is MiniLM, 384 dimensions, from Hugging Face / sentence-transformers.

Why

So paraphrase clusters. Keyword overlap is optional. That is the only reason “cute dog” can retrieve a golden retriever.

How

Pick a provider (Hugging Face OSS, OpenAI paid, Google APIs), embed at write, embed the query with the same model, compare cosine. Swap the model → rebuild the index.

In production

Search and recommend sit on the same map

Semantic search

Query meaning, not title match. Image and text both work once they are vectors.

Recommendations

Nearest neighbors of what you already consumed. Same index type as RAG.

Providers

Start on Hugging Face locally (this course). Move to a hosted embedding API only when you need a larger model or SLA.

                        How eval works

                        Golden-set regression against the live LangGraph agent — on demand, no CI/CD required

                        1. Load golden cases — agent/evals/golden_alerts.json (8 fixtures: checkout, payment, auth, DB pool…)
                        2. Invoke agent — each case runs the real graph: classify → Chroma RAG → logs → metrics → recommend → HITL
                        3. Score per case
                          • RAG Recall@3 — expected runbook in top-3 Chroma results
                          • Groundedness — recommendation mentions runbook keywords
                          • Correctness — actual runbook_id matches expected
                          • Tool / HITL accuracy — requires_hitl matches expects_hitl flag
                          • P95 latency — end-to-end graph time per case
                        4. Gate verdict — PASS if all averages meet thresholds (RAG ≥85%, groundedness ≥80%, correctness ≥85%, latency ≤8s)
                        5. LLM-as-judge — a judge prompt scores groundedness; that score is published into Langfuse
                        6. Publish — results saved locally, then pushed only to this design’s eval tool (Langfuse datasets / Phoenix / MLflow)

                        Practice: Switch design → Run Eval Suite → open Langfuse / Phoenix / MLflow for that design only.
